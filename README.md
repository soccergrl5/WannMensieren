# Project for TUM.ai Makeathon 2026
WannMensieren is a Project from the TUM.ai Makeathon 2026.

## The given Problem
Student live is difficult and you have to manage a lot of different stuff.
So Create something that will make student live easier.

## Our Idea
What is the most important thing when it comes to planing your courses for the next semester?
Correct, that you have time to eat lunch every day.
WannMensieren is an App thats trying to solve that.
Just select the Courses that are interessting to you and get diffrent Results, that make sure, you have time to go to lunch every single day.
